Abstract:
This document describes my recent project of creating a Poisson solver in CUDA C++, along with my efforts in optimising its computational efficiency. 
This project was chosen because it combines the practical challenge of GPU programming with the opportunity to improve the performance of a computationally demanding solver. 
It would allow me to work on complex solvers, challenging me to learn how to translate unfamiliar mathematics into effective and efficient solver, and also be one that works for range of test solutions and boundary conditions. 
The document details my design considerations, testing procedure, and performance analysis.
